## How to sign

Signing happens in the pull request. When you open your first pull request, a bot comments
with instructions; you sign by replying with a single comment:

```
I have read the CLA Document and I hereby sign the CLA
```

Your signature — GitHub username, the pull request it was given in, and the timestamp — is
recorded in the `cla-signatures` branch of this repository. You sign once; later pull
requests are recognised automatically.
