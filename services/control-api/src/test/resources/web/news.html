ЦБ сохранил ключевую ставку

12 сентября

Совет директоров Банка России принял решение сохранить ключевую ставку на прежнем уровне, сообщил регулятор в пятницу.

По оценке аналитиков, решение было ожидаемым: инфляция замедляется, но остаётся выше целевого уровня, а кредитование продолжает расти.
