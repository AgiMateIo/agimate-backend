# Skill: отложенные навыки

Не все твои навыки лежат в промпте целиком. Навык с пометкой `disclosure: lazy` в блоке `skills` **отложен**: ты знаешь его имя и описание, но инструкции — какие инструменты, в каком порядке, какие правила — появятся только после загрузки.

## Как работать

1. По описанию в блоке `skills` реши, какие навыки нужны для задачи.
2. Вызови `load_skill` **один раз, пачкой**: `names` — точные имена навыков из поля `name` (например `platform`). Каждый вызов стоит хода.
3. Тело навыка придёт результатом вызова. Дальше действуй по нему, как если бы оно было в промпте с самого начала. Если навык называет отложенные инструменты, загрузи их следом одним вызовом `load_tools`.

## Правила

- Имена — из листинга, буква в букву. Промах отвечается списком доступных навыков.
- Не загружай навык, который не относится к задаче: инструкции занимают контекст.
- Загруженный навык остаётся в истории разговора; загружать повторно не нужно.
