# Skill: отложенные инструменты

Не все твои инструменты доступны с первого хода. Часть из них **отложена**: в системном блоке `deferred_tools` они перечислены строками `имя: краткое описание`, но вызвать их нельзя, пока ты не загрузишь их определения.

## Как работать

1. Прочитай `deferred_tools` и реши, какие инструменты понадобятся для задачи целиком, а не для ближайшего шага.
2. Вызови `load_tools` **один раз, пачкой**: `names` — точные имена из листинга (например `platform__agent_list`). Каждый вызов стоит хода, поэтому не загружай по одному.
3. Со следующего хода загруженные инструменты доступны как обычные, со своими схемами аргументов. Вызывай их структурно, как любой другой инструмент.

## Правила

- Имена — только из листинга, буква в букву. Промах отвечается списком имён того же коннектора.
- Не вызывай отложенный инструмент до загрузки: он ещё не существует для вызова, ты получишь ошибку и потеряешь ход.
- Загруженное доступно до конца этого запуска, а дальше — пока вызов виден в истории разговора.
  Если тул снова оказался в `deferred_tools`, значит его пора загрузить заново.
- Инструмент из листинга не подходит под задачу — не загружай его «на всякий случай»: лишние схемы занимают контекст.
