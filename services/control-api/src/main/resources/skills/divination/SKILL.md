# Skill: AgiMate Divination

## Главное правило

**Никогда не считай числа и не «вытягивай» карты сам.** Арканы Матрицы, числа жизненного пути и выпавшие карты Таро всегда бери из тулов — пользователь может пересчитать и проверить. Интерпретация — твоя; факты — движка.

---

## Инструменты

### divination.matrix_of_destiny

Матрица судьбы по дате рождения (арканы 1–22, редукция сумм больше 22).

| Параметр | Тип | Описание |
|----------|-----|----------|
| `birthDate` | string | Дата рождения `YYYY-MM-DD` |

Возвращает: `points` — энергии точек (`day` — характер, `month` — таланты, `year` — карма рода, `mission` — кармическая задача, `center` — зона комфорта, `paternalLine`/`maternalLine` — родовые линии, `southEast`/`southWest`), `moneyLine` (`money`, `relationships`), `karmicTail` — три аркана кармического хвоста. Интерпретируй каждое число как соответствующий старший аркан Таро.

### divination.numerology

Нумерология по дате рождения: число жизненного пути (мастер-числа 11/22/33 сохраняются), число дня рождения, персональный год.

| Параметр | Тип | Описание |
|----------|-----|----------|
| `birthDate` | string | Дата рождения `YYYY-MM-DD` |

Возвращает: `lifePath` (`value`, `isMaster`, `components` — день/месяц/год по отдельности), `birthdayNumber`, `personalYear`. Если `isMaster: true` — обязательно раскрой особый смысл мастер-числа.

### divination.tarot_card_of_day

Карта дня пользователя. **Детерминирована**: один пользователь — одна и та же карта весь день, сколько ни спрашивай. Не тяни карту дня через расклад — только этим тулом.

| Параметр | Тип | Описание |
|----------|-----|----------|
| `date` | string? | Дата `YYYY-MM-DD` (UTC); по умолчанию — сегодня |

Возвращает: `card` (`nameRu`/`nameEn`, `arcana`, `suit`, `number`, `reversed`, `keywords` — уже для актуальной ориентации), `sameForWholeDay: true`.

### divination.tarot_draw_spread

Случайный расклад из полной колоды 78 карт Райдера–Уэйта, без повторов, каждая карта может выпасть перевёрнутой.

| Параметр | Тип | Описание |
|----------|-----|----------|
| `spread` | string | `THREE_CARD` (прошлое/настоящее/будущее), `CELTIC_CROSS` (10 позиций), `YES_NO` (1 карта) |
| `question` | string? | Вопрос пользователя (для контекста) |

Возвращает: `cards` — карты с позицией в раскладе (`position`), ориентацией (`reversed`) и ключевыми словами.

---

## Паттерны

- Перед раскладом сформулируй с пользователем вопрос, потом **один** вызов `tarot_draw_spread`. Не перетягивай карты, если ответ «не понравился», — так расклад теряет смысл; повторный расклад на тот же вопрос — только по явной просьбе.
- Интерпретируй карту по её позиции в раскладе и ориентации; ключевые слова из тула — опора, развёрнутое значение — твоя экспертиза.
- «Быстрый ответ да/нет» → `YES_NO`; «разбор ситуации» → `THREE_CARD`; «глубокий разбор» → `CELTIC_CROSS`.
- Матрицу и нумерологию красиво объединяй в один разбор личности — обе строятся от одной даты рождения, показывай перекликающиеся темы.
