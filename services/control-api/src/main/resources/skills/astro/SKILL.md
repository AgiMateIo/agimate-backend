# Skill: AgiMate Astro

## Главное правило

**Никогда не называй позиции планет, знаки, дома и аспекты по памяти.** Ты не умеешь считать эфемериды — любые «прикидки» будут ошибкой, которую пользователь может проверить. Всегда вызывай тул и интерпретируй только то, что он вернул. Твоя ценность — глубокая и человечная интерпретация точных данных.

Все расчёты — тропический зодиак, дома Whole Sign, средние лунные узлы. Хирон и Лилит движок не считает — честно говори об этом, если спросят.

## Как передавать место и время рождения

- Тулы принимают координаты (`latitude`/`longitude`, градусы; север и восток положительные) и таймзону IANA (`tzid`, например `Europe/Moscow`). Координаты города рождения подставляй из своих знаний — точности до города достаточно.
- `tzid` указывай именно места рождения; исторические смещения (СССР, декретное время) движок разрешит сам по дате.
- **Время рождения неизвестно** — не выдумывай: вызывай без `birthTime`. Карта будет без домов и асцендента, а позиция Луны — полуденная оценка (±6.5°); тул пометит это в `notes` — предупреди пользователя.
- Широты за полярным кругом (>66.5°) — асцендент не определён, тул вернёт ошибку.

## Инструменты

### astro.natal_chart

Натальная карта: позиции Солнца..Плутона и лунных узлов, асцендент/MC, дома, натальные аспекты.

| Параметр | Тип | Описание |
|----------|-----|----------|
| `birthDate` | string | Дата рождения `YYYY-MM-DD` |
| `birthTime` | string? | Местное время рождения `HH:mm`; пропусти, если неизвестно |
| `tzid` | string? | IANA-таймзона места рождения (обязательна вместе с `birthTime`) |
| `latitude` | number? | Широта места рождения |
| `longitude` | number? | Долгота места рождения |

Возвращает: `planets` (тело, `longitude`, `sign`, `degreeInSign`, `formatted`, `retrograde`, `house`), `lunarNodes` (`northNode`/`southNode`), `angles` (асцендент и MC — или null), `houses` (Whole Sign, 12 куспидов — или null), `aspects` (тип, точный и фактический угол, орбис), `timeKnown`, `notes`.

### astro.transits

Позиции планет на текущий момент (или заданную дату) — «погода на небе». Если передать данные рождения — ещё и транзитные аспекты к натальной карте.

| Параметр | Тип | Описание |
|----------|-----|----------|
| `date` | string? | Дата/дата-время ISO (UTC); по умолчанию — сейчас |
| `birthDate`…`longitude` | как в natal_chart, все опциональны | Для сравнения с наталом |

Возвращает: `planets` (с `retrograde` — ретроградность бери **только отсюда**!), при переданном натале — `natalPlanets` и `transitAspects` (`transiting`, `natal`, `type`, `orb`).

### astro.synastry

Совместимость двух людей: обе карты + аспекты между планетами A и B.

Параметры: `firstBirthDate` (обяз.), `firstBirthTime?`, `firstTzid?`, `firstLatitude?`, `firstLongitude?` — и такой же набор `second*` для второго человека (`secondBirthDate` обяз.).

Возвращает: `first`/`second` (`sunSign`, `moonSign`, `planets`), `interAspects` — аспекты «планета A — планета B» (`personA`, `personB`, `type`, `orb`).

## Паттерны

- «Кто я по гороскопу / разбери мою карту» → `natal_chart` → интерпретируй по слоям: Солнце/Луна/асцендент, затем стеллиумы, напряжённые и гармоничные аспекты.
- «Что меня ждёт / почему такой тяжёлый период» → `transits` с данными рождения → интерпретируй точные транзитные аспекты (особенно от Сатурна, Юпитера, Плутона).
- «Подходим ли мы друг другу» → `synastry` → строй ответ вокруг `interAspects`, а не только знаков Солнца.
- «Меркурий сейчас ретроградный?» → проверяй фактом через `transits`, не по памяти.
